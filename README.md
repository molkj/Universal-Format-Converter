# 文件转换助手 v1.22.0

一个**纯本地、免费、免安装**的批量文件格式转换工具。所有转换都在你自己的电脑上完成，文件不会上传到任何服务器，断网也能用。

> 📱 手机版：`FileConverter-Android/` 提供了 Android Studio 项目（图片批量转换），见 [README-Android.md](FileConverter-Android/README-Android.md)

## ✨ 功能亮点

- **视频 GPU 硬件加速**：自动检测 NVIDIA/AMD/Intel 显卡，视频转码提速 5-10 倍，无 GPU 自动回退 CPU
- **多线程并发转换**：多个文件同时转换（并发数可在设置中调整 1-8）
- **图片合并为 PDF**：多张图片一键合并成一个 PDF 文档
- **结果打包 ZIP**：转换完成自动把成功输出打包成压缩包
- **记忆输出目录**：记住你上次选择的输出目录，下次启动自动恢复
- **取消自动清理**：转换中途取消，正在写的未完成文件自动删除，不留垃圾
- **设置面板**：并发数、GPU 加速开关集中管理（⚙ 设置）
- **拖拽即用**：把文件或文件夹直接拖进窗口即可添加
- **批量设置格式**：勾选多个文件，一键统一目标格式
- **表头全选**：点击表头勾选框全选 / 全不选（快捷键 `Ctrl+A` / `Ctrl+Shift+A`）
- **智能勾选**：转换成功的文件自动取消勾选，避免下次重复转换
- **实时反馈**：每行独立进度条、底部汇总、转换完成进度条变绿（有失败变红）
- **快捷键**：`Ctrl+A` 全选、`Ctrl+Shift+A` 全不选、`Delete` 移除选中行、`Ctrl+O` 添加文件
- **完整信息展示**：选中任意文件，底部状态栏显示完整名称 / 大小 / 目标格式 / 路径
- **日志面板**：点击「📋 显示日志」查看每次转换的详细记录

## 快速上手

1. 双击运行 `文件转换助手.exe`（约 115MB，纯绿色免安装）
2. 把文件（或文件夹）**拖进窗口**，或点击「＋ 添加文件 / ＋ 添加文件夹」
3. 勾选要转换的文件，为每个文件选择目标格式（下拉框），或用「⚙ 批量设置格式」统一设置
4. 点击「▶ 开始转换」——多个文件会**并发**同时转换
5. 默认不自动打开输出目录；可勾选「完成后自动打开输出目录」「完成后打包 ZIP」启用

> 输出目录默认在 `文档/格式转换输出`，可通过标题栏「更改…」调整，**下次启动会记住你的选择**。

## 支持的转换

### 📄 文档

| 转换                     | 说明                          |
| ---------------------- | --------------------------- |
| PDF → Word             | 还原排版为可编辑的 .docx             |
| PDF → 文本 / 图片          | 提取文字，或每页导出 PNG/JPG/WebP     |
| Word → PDF             | 需本机安装 Office 或 WPS（自动调用）    |
| Word → 文本 / Markdown   | 提取全部文字                      |
| TXT / Markdown → Word  | 支持标题、列表样式                   |
| Markdown → HTML / Word | 渲染为网页或文档                    |
| Excel → CSV / 文本       | 导出首个工作表                     |
| CSV → Excel            | 表格化                         |
| XLS → XLSX             | 老版 Excel 升级                 |
| PPT → PDF / 文本         | 需本机安装 Office 或 WPS（转 PDF 时） |

### 🖼 图片

PNG / JPG / WebP / GIF / BMP / TIFF / ICO 任意互转，自动处理透明背景与图标尺寸。

### 🎬 音视频

- 视频互转：MP4 / MKV / AVI / MOV / WEBM / FLV / WMV / M4V
- 音频互转：MP3 / WAV / AAC / FLAC / OGG / M4A / WMA
- 视频 → 音频：一键提取音轨
- 视频 → GIF：转动态表情包
- 视频 → 图片：提取封面帧

### 🗜 压缩包

- 解压：ZIP / 7Z / TAR / GZ / TGZ → 文件夹
- 打包：文件夹 → ZIP / 7Z / TAR.GZ
- 互转：ZIP ↔ 7Z ↔ TAR.GZ

## 小技巧

- **多选批量操作**：按住 `Ctrl` 点击多行，或先勾选再点「⚙ 批量设置格式」（未选中行时自动对所有已勾选文件生效）
- **查看完整路径**：鼠标悬停文件名，或点击该行看底部状态栏
- **重新转换失败项**：失败的任务会标红，重新勾选后点「开始转换」即可重试（可先改目标格式）
- **快捷移除**：选中行按 `Delete` 删除；「🗑 清空」一键清空列表
- **转换中可取消**：点「取消」停止剩余任务，**正在写的未完成文件会自动删除**，已成功的不受影响

## 常见问题

**Q: Word/PPT 转 PDF 失败？**  
A: 此功能需要电脑上装有 Microsoft Office 或 WPS Office。安装后重启本工具即可。

**Q: 转换很慢？**  
A: 大视频、大 PDF 需要时间，属正常现象。工具默认 4 路并发，可同时处理多个文件。

**Q: 文件会被上传吗？**  
A: 不会。所有转换全部在本地完成，断网也能用。

**Q: 为什么有的文件不能添加？**  
A: 只有工具支持的类型（文档 / 图片 / 音视频 / 压缩包）才能添加，其他类型会被自动跳过。

## 目录结构（开发者）

```
FileConverter/
├── main.py            # 程序入口
├── gui.py             # PySide6 图形界面（含多线程并发调度、目录记忆、取消清理）
├── converter/         # 转换引擎
│   ├── registry.py    # 全局注册表（格式→转换函数）
│   ├── document.py    # 文档/PDF/Office 转换
│   ├── image.py       # 图片转换（Pillow）
│   ├── media.py       # 音视频转换（ffmpeg）
│   ├── archive.py     # 压缩包处理
│   └── utils.py       # 工具函数（含取消机制）
├── build.spec         # PyInstaller 打包配置（体积优化：UPX + excludes）
├── make_icon.py       # 应用图标生成脚本
├── FileConverter-Android/  # 手机版 Android Studio 项目
└── assets/            # 应用图标等资源
```
